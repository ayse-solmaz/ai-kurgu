# Müzik kütüphanesi

Lisansını bildiğiniz (tercihen CC0 / telifsiz) müzikleri ruh haline göre klasörlere koyun:

```
assets/music/calm/
assets/music/upbeat/
assets/music/inspiring/
assets/music/dramatic/
assets/music/corporate/
```

Desteklenen biçimler: mp3, wav, ogg, m4a, flac. Planlayıcı videoya uygun ruh halini seçer; müzik
konuşma sırasında otomatik olarak kısılır (ducking). Klasör boşsa müzik eklenmez.
